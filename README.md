# SeekBar, Switch e ToggleButton

App Android com duas telas para praticar componentes de interação.

## O que o app faz

**Tela 1 — Cálculo de porcentagem**
- Uma `SeekBar` de 0 a 100: ao arrastar, o valor aparece na tela ("Valor: 42").
- Um `Toast` avisa quando o usuário começa a ajustar ("Ajustando o valor") e quando solta ("Ajuste concluído").
- O botão **Segunda Tela** abre a próxima Activity com `Intent`.

**Tela 2 — Switch, ToggleButton e CheckBox**
- O `Switch` liga e desliga o `ToggleButton` e o `CheckBox` (eles começam desativados).
- O botão **Verificar** mostra o estado de cada um: Switch ligado/desligado, Toggle ligado/desligado e CheckBox selecionado ou não.

Usa View Binding para acessar os componentes da tela.
